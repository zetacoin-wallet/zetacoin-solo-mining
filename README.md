This repository covers the two ways Zetacoin is produced: mining and staking. It exists because the wallet
does both from one window, and most of the confusion around ZET comes from mixing the two up.

Mining here means Scrypt. The chain moved from SHA-256 in 2021, so the older hardware does not apply, and the guides say
which machines still work, how a pool worker is configured, and what running solo through the wallet actually involves.
Staking needs no hardware and no minimum balance: coins need roughly eight hours to mature, the wallet has to be open and
synced, and the reward is a fixed 0.0625 ZET per coinstake block rather than a percentage anyone can quote in advance.

The pages are written for one machine and a normal electricity bill. They state the trade-offs between an ASIC, a GPU and
coins left staking instead of implying that any of them is free money, and they explain how to confirm that a reward
really arrived in the transaction list. The wallet itself comes from this account, and its release page carries the
checksums worth checking before you run a miner for a week.
